# Thiết lập và tiếp tục dự án

Đọc AGENTS.md → management/OPERATING-MODEL.md → management/backlog/STATUS.md.
Nhật ký bền vững đặt tại vault theo AGENTS.md. Mọi agent cần đọc checkpoint trước khi làm.
Đợt hiện tại chỉ thiết lập phối hợp. Xem management/MODELS.md cho mức xác minh model,
management/reviews/ cho review và trạng thái runtime.
